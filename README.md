# LilBot

Ble lei av å ikke få tak i Pokemon.

Varsler for Pokemon TCG-produkter i norske nettbutikker, med handlekurv og Vipps-forespørsel rett fra varselet.

**Last ned:** [siste versjon](https://github.com/martinhofff/lilbot/releases/latest)

- Windows: `LilBot-Setup-…exe`
- Mac med Apple-chip (M1, M2, M3, M4): `LilBot-…-mac-arm64.dmg`
- Mac med Intel: `LilBot-…-mac-x64.dmg`

Usikker på hvilken Mac du har? Klikk på eplet øverst til venstre på skjermen og velg «Om denne Macen». Står det Apple M1, M2, M3 eller M4, ta arm64. Står det Intel, ta x64.

**Første gang på Windows:** står det «Windows beskyttet PC-en», trykk «Mer informasjon», så «Kjør likevel».

**Første gang på Mac:** åpne .dmg-filen og dra LilBot inn i Programmer. Høyreklikk LilBot i Programmer og velg Åpne, så Åpne igjen. Får du bare valget «Flytt til papirkurven»: gå til Systeminnstillinger › Personvern og sikkerhet, bla ned og trykk «Åpne likevel». Etter det åpner den som vanlig.

LilBot krever en kode. Skriv `/lilbot` i Discorden for å få koden din. Krever rollen @LilBot Access.
