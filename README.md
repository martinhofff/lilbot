# LilBot

Ble lei av å ikke få tak i Pokemon.

Varsler for Pokemon TCG-produkter i norske nettbutikker, med handlekurv og Vipps-forespørsel rett fra varselet.

**Last ned:** [siste versjon](https://github.com/martinhofff/lilbot/releases/latest)

LilBot krever en kode. Skriv `/lilbot` i https://discord.gg/JHhzaUjAH for å få din.
